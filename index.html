PLATFORM CAPABILITY MATRIX — mapped to PS 26187 scope

LIVE Real-Time Object Detection COCO-SSD/TensorFlow.js person & object detection running on existing CCTV/webcam feeds — no proprietary hardware.
LIVE Crowd Counting & Threshold Alerts Live headcount, peak/average tracking, and audible + visual alerts when a zone exceeds a configurable threshold.
LIVE Evidence Capture One-click screenshot and video recording of flagged events, timestamped for chain-of-custody logging.
ROADMAP Intrusion / Perimeter Detection Virtual tripwire zones on the video canvas to flag unauthorized crossing near Border Out Posts.
ROADMAP Facial Recognition (FRS) Watchlist matching against a local encrypted database for repeat-offender / suspect identification.
ROADMAP ANPR Automatic number-plate recognition for vehicles at check posts and border roads.
ROADMAP Multi-Object Tracking Persistent ID tracking across frames for movement-pattern analysis along border stretches.
ROADMAP Multi-Camera / Edge Deployment Runs client-side in-browser today; architecture designed to scale to distributed BOP camera feeds.
